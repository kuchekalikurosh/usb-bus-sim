# usb-bus-sim
A Linux kernel module that simulates block level USB storage I/O operations

This project was developed as part of my operating systems and systems programming studies. The goal of the simulation was to model communication between USB devices and a kernel-level USB bus while exploring concepts such as device polling, read/write operations, buffering, synchronization, and low-level resource management.

Unlike many of the application-level projects I had worked on previously, this project focused heavily on systems-level programming concepts and exposed me to the complexity behind hardware abstraction and operating system interactions.

# Technical Concepts
- USB device communication simulation
- Read/write request handling
- Linux-style kernel interaction
- Buffer management
- Thread synchronization
- Low-level memory/resource handling
- Concurrent device operations
